# TechDocs status

Due to the lengthy history of the codebase, consolidating the different versions and edits of the technical documentation (TechDocs) is a work in progress.

- `Markdown` is now the "reference" version where all changes and fixes should be made. This is also what the documentation website is built from.
- The `html` version is still kept for now because it contains genuinely distinct content. It has been taken from the Nokia 9110 SDK, which in addition to documentation of TCP-related protocol APIs also describes some Nokia-specific libraries (e.g `foam`) for which source code is not publicly available.
- The old `ascii` version of the documentation (from Casio Zoomer SDK) has been removed to avoid confusion, because it has been fully integrated into the Markdown version.
